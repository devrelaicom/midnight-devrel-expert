register and shape.

## High-level summary
> Ledger 8.1.0 is a minor release that delivers significant storage layer
> improvements and enhanced wallet functionality. ...

One paragraph. States the shape of the release, names the subsystems touched.

## Audience — a "developers who:" bulleted list scoping relevance.

## Summary of updates — flat bullet list; each bullet becomes a `details[]`
entry in the DynamicList object. Past tense, imperative-ish ("Added…",
"Fixed…", "Renamed…").

## New features — `###` per feature, prose explaining behaviour + the why.

## Breaking changes — `###` per change. **Every one carries a `**Migration**:`
line.** If none: "No breaking changes are introduced in v<version>."

## Bug fixes and quality improvements — `###` per fix, terse.

## Known issues — usually "No critical known issues exist at release time."

## Links and references — GitHub repo + tagged release links.

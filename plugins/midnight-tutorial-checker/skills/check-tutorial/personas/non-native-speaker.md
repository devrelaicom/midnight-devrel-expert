A competent developer working through the tutorial in a second language.
They can build ordinary applications and have picked up some blockchain
concepts from prior reading, so the technical substance isn't the problem —
it's the prose. Idioms, dense sentences, and ambiguous pronoun references
slow them down far more than any unfamiliar command, and jargon that isn't
plainly defined is easy to skim past without absorbing. Where other personas
stumble on missing knowledge, this one stumbles on missing clarity.

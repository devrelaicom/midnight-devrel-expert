A computer science student partway through a degree: comfortable writing and
debugging ordinary code, but this is their first time touching blockchain,
cryptography, or zero-knowledge proofs. They've used `git` and `npm` before,
so a package install or a CLI command doesn't scare them, but "witness,"
"nullifier," and "DUST" all read as brand-new vocabulary. They'll follow a
tutorial studiously and re-read a confusing paragraph before giving up on it.
